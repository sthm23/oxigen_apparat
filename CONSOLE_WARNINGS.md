# Предупреждения в консоли разработки

## Безопасные предупреждения, которые можно игнорировать:

### 1. "Encountered a script tag while rendering React component"

**Причина:** Библиотека `next-themes` добавляет inline `<script>` тег для предотвращения мигания темы при загрузке страницы.

**Почему это безопасно:**
- Это стандартная практика для систем тем
- Скрипт выполняется до гидратации React
- Предотвращает визуальное мигание при переключении между светлой и темной темами
- Не влияет на функциональность приложения

**Решение:** Это предупреждение можно безопасно игнорировать. Оно появилось в React 19 как информационное предупреждение о новых правилах рендеринга.

---

### 2. "Cannot read properties of undefined (reading 'search')"

**Причина:** Это предупреждение исходит от браузерных расширений (обычно React DevTools или другие инструменты разработчика), которые пытаются получить доступ к `window.location.search` до полной инициализации страницы.

**Почему это безопасно:**
- Ошибка происходит вне вашего кода приложения
- Исходит от browser extension: `at sendElementToArc (<anonymous>:44:37)`
- Не влияет на работу сайта

**Решение:** 
- Можно игнорировать
- Или отключить расширения браузера во время разработки
- Это не появляется в production build

---

## Как проверить, что ваш код работает правильно:

1. ✅ Откройте сайт в браузере: http://localhost:3000
2. ✅ Переключите язык (RU/UZ/EN) - всё работает
3. ✅ Переключите тему (светлая/темная) - нет мигания
4. ✅ Все тарифы и цены отображаются корректно
5. ✅ Телефон и Telegram ссылки кликабельны

## Важно:

В **production build** (`npm run build` && `npm start`) эти предупреждения НЕ появляются в консоли, так как:
- Development режим более строг с предупреждениями
- Production build оптимизирован и не показывает эти сообщения

---

## Если хотите полностью убрать предупреждения в development:

Можно отключить React DevTools расширение в браузере для этого проекта, но это не обязательно.
