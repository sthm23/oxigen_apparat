# 🔄 Руководство по очистке кеша метатегов Open Graph

## Проблема
Социальные сети кешируют метатеги (Open Graph) при первом просмотре ссылки и не обновляют их автоматически после изменений на сайте.

## ✅ Решения

### 1. Facebook / Meta / WhatsApp / Instagram

**Facebook Sharing Debugger:**
1. Откройте: https://developers.facebook.com/tools/debug/
2. Вставьте URL вашего сайта: `https://kislorodpro.uz`
3. Нажмите **"Debug"** или **"Отладка"**
4. Нажмите **"Scrape Again"** / **"Очистить кеш"** / **"Получить новую информацию"**
5. Проверьте обновленные данные в превью

**Важно:** Этот инструмент также обновляет кеш для:
- WhatsApp
- Instagram
- Facebook Messenger

### 2. LinkedIn

**LinkedIn Post Inspector:**
1. Откройте: https://www.linkedin.com/post-inspector/
2. Вставьте URL: `https://kislorodpro.uz`
3. Нажмите **"Inspect"**
4. Дождитесь обновления превью
5. Проверьте новые данные

### 3. Twitter / X

**Twitter Card Validator:**
1. Откройте: https://cards-dev.twitter.com/validator
2. Вставьте URL: `https://kislorodpro.uz`
3. Нажмите **"Preview card"**
4. Проверьте обновленное превью

**Альтернатива (если validator не работает):**
- Просто твитните ссылку в черновике (Draft) и проверьте превью
- Удалите черновик после проверки

### 4. Telegram

**Через бота @webpagebot:**
1. Откройте любой чат в Telegram
2. Найдите бота: `@webpagebot`
3. Отправьте команду:
   ```
   /updatepreview https://kislorodpro.uz
   ```
4. Дождитесь подтверждения

**Альтернатива:**
- Отправьте ссылку в "Избранное" (Saved Messages)
- Если превью старое, подождите 24 часа или используйте бота

### 5. Discord

**Discord не имеет официального инструмента, но:**
1. Добавьте query параметр к URL: `https://kislorodpro.uz?v=2`
2. Discord увидит это как новую ссылку и обновит кеш
3. После первого просмотра можно делиться обычной ссылкой

### 6. Slack

**Slack не имеет публичного инструмента:**
1. Используйте query параметр: `https://kislorodpro.uz?refresh=1`
2. Или дождитесь автоматического обновления (обычно 24 часа)

## 🚀 Проверка обновлений

После очистки кеша проверьте:

1. **Откройте инструменты разработчика** (F12 в браузере)
2. Перейдите во вкладку **Network** / **Сеть**
3. Обновите страницу (Ctrl+F5)
4. Найдите HTML документ
5. Проверьте заголовки ответа:
   ```
   <meta property="og:title" content="kislorodpro.uz - Кислородные концентраторы">
   <meta property="og:description" content="...☎️ +998 99 011 11 99 · +998 95 033 73 73">
   ```

2. **Meta Tags Checker**: https://metatags.io/

Просто вставьте URL и проверьте, как выглядит превью в разных соцсетях.

## 🔧 Если проблема сохраняется

### На стороне сервера:

1. **Очистите CDN кеш** (если используете Cloudflare, Vercel и т.д.)
   - Cloudflare: Dashboard → Caching → Purge Everything
   - Vercel: Автоматически очищается при деплое

2. **Проверьте HTTP заголовки:**
   ```bash
   curl -I https://kislorodpro.uz
   ```
   
   Убедитесь, что нет агрессивного кеширования:
   - `Cache-Control: no-cache` или `max-age=0` для HTML
   - Избегайте `max-age=31536000` для HTML файлов

3. **Форсируйте редеплой** на хостинге (Vercel, Netlify и т.д.)

### Временное решение:

Используйте версионирование URL при шаринге:
```
https://kislorodpro.uz?v=2
https://kislorodpro.uz?update=2026-08-19
```
